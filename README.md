# n1ght-k1ng.github.io

Personal site of **D Nikhil Reddy**, a backend engineer (Node.js · TypeScript · AWS).

**Live:** https://n1ght-k1ng.github.io

It's a single static page (`index.html`, plus a photo in `assets/`), with no framework and no build step.
GitHub Pages serves it straight from the root of `main`, and `.nojekyll` turns off Jekyll processing.

To preview locally:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```
